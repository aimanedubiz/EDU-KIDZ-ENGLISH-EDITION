📖 COORDINATES GAME GUIDE

📍 Year 3 Coordinate Skills:

  • Positions: Columns A to D run from left to right. Rows 1 to 4 run from bottom to top.
  • Reading Coordinates: Write the column first and the row second, for example (A, 1) or (B, 3).
  • Grid Symbols: Animals, fruit, vehicles and houses appear in squares on the grid.

🎮 Game Formats:

  • Multiple Choice: Choose one answer from A, B, C or D.
  • Interactive Grid: Select the target square on the grid.
  • Fill in the Blank: Type the column letter, coordinates or object name requested.
